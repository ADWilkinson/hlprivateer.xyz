# web

Next.js web app for the public HL Privateer surface.

## Runtime Notes

- `/` explains the v3 HIP-4 outcome-market system and its deterministic safety boundary.
- `/floor` renders the privacy-safe live loop: mode, public markets, pHat, edge, and AGT / RSK / EXE / OPS tape.
- Local development expects the agent API on `http://127.0.0.1:4100` unless `NEXT_PUBLIC_API_BASE_URL` is set.
