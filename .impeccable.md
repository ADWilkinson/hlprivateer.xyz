## Design Context

### Users
HL Privateer is for technical operators, builders, and curious agents who want
to understand how an LLM-driven outcome-market trading loop behaves without
seeing private positions, bankroll, raw signals, or operator strategy.

### Brand Personality
Calm, precise, and transparent. The interface should feel like an instrumented
control room: sparse, legible, alive with telemetry, and allergic to hype.

### Aesthetic Direction
Refined terminal minimalism with a light industrial palette. Use mono typography,
thin rules, compact tables, status tape, and restrained motion that shows the
pipeline working. Avoid marketing-page gloss, oversized hero cards, purple
gradients, decorative bokeh, and vague "AI agent" language.

### Design Principles
- Make the pipeline visible: every screen should show how raw sentiment becomes
  an agent proposal, a deterministic risk decision, and then either DENY or fill.
- Prefer exact operational language over vibes: name gates, caps, endpoints, and
  failure modes directly.
- Keep public surfaces privacy-safe: expose pHat, edge, mode, and tape; never
  expose bankroll, positions, notionals, raw signals, or thesis by accident.
- Use motion as system state, not decoration. Respect reduced motion.
- Keep code and copy small enough that a new operator can audit the whole thing.
